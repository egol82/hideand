# Visual reference and implementation evidence

The concept images previously generated in the ChatGPT conversation are not included as binary assets in this Git branch. They are not runtime screenshots and are not required for the game to run.

For actual implementation evidence, open the Godot validation workflow's `godot-4.7.2-validation` artifact. It contains five screenshots rendered by Godot with software OpenGL, plus test logs. Artifact retention is seven days; save a copy when reviewing a particular build.

Use docs/ART_BIBLE.md for the current shared toy-material rules. Do not recreate the old flat black scribble/polished-room mismatch.
