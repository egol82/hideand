# Hide & Smashing — Phase20

직접 그린 장난감 무기로 숨고, 찾고, 반격하는 게임입니다.

## 새 야외 자연 맵 3종

- **솔방울 숲**: 거목 주변 고리형 추격, 통나무 엄폐, 조용한 이끼 우회로.
- **갈대 물굽이**: 갈대섬 두 개 사이 북쪽·중앙·남쪽 연결로, 시끄러운 나무길과 조용한 둑길.
- **노을 협곡**: 엇갈린 바위 지형, 좁은 틈과 넓은 외곽길, 돌 아치 랜드마크.

각각34x30 /40x32 /42x34m, 은신처10곳(기존 가짜 은신처 규칙 포함), 실제 바닥·충돌·경로·두 경기 모드로 동작합니다. 색만 바꾼 맵이 아닙니다. 물은 얕은 장식이며 수영이나 추락 사망을 추가하지 않습니다.

`phase20/nature-playgrounds`에서 **Godot Standard로 project.godot → F5 → 맵 선택 → 술래/숨는 역할**.
기존7맵과 대저택GI·캐릭터·셰이더·둥근 손·그림 비례 무기·HUD·타격 싱크·애니메이션·은신·저장 기능을 유지합니다. 야외맵 조명은 직접광이며 새GI 베이크가 아닙니다.

그래픽 비교 → 맵 마감의 작은 장식 거리 옵션은 새맵의 풀·꽃에도 적용됩니다. 큰 나무/바위/갈대엄폐와 은신처는 거리로 제거하지 않습니다. 자유 연습 버튼은 기존대로 토이하우스를 엽니다.

검사: `python tools/test_outdoor20.py --matches`, 실제 화면은 Xvfb/디스플레이에서 `--capture` 추가.
상세 구현/결과는 docs/PHASE20.md, docs/PHASE20_TEST_STATUS.md. 자동검사는 사람 재미·숨기 가독성·하드웨어 FPS 인증이 아닙니다. main/이전PR 병합·프로덕션배포 없음. 유료에셋·폰트·엔진·캐시·개인저장은 배포하지 않습니다.


## Phase21 · 2단계: Reedwater Bend 상호작용

Pine Hollow의 낙엽·4초 공유 수풀을 유지하고 습지에 짧은 이동 단서를 추가했습니다.
물길2곳의 실제 발걸음은3초 물 흔적을 남기고, 젖은 발은 물을 나온 뒤 최대2.5초의
실제 발걸음에만 흔적을 남깁니다. 네 갈대 구역은 발걸음에 반응해1.5초 흔들리고
짧은 지면 흔적/소리를 남깁니다. 만료된 단서는 기존 조사 도구에서도 사라집니다.

`project.godot` → F5 → **Reedwater Bend / 갈대 물굽이**. 새 단축키는 없습니다.
기존 나무길/둑길로 우회할 수 있고, 조용히 걸으면 소리 반경은 줄지만 흔적은 남습니다.
움직이지 않는 사람이나 은신 중인 사람을 계속 표시하는 기능은 없습니다.
원래10개맵·충돌·검색·잡기·타격·두모드 규칙은 유지합니다.

작업 브랜치는 `phase21/living-nature`, stacked draft PR #21의 base는
`phase20/nature-playgrounds`입니다. 습지 증분의 상세/검증은 `docs/PHASE21B.md`를 봅니다.
협곡 상호작용과 전체 seed 변주는 아직 추가하지 않았습니다. 사람의 재미/밸런스와
사용자 하드웨어 성능은 미검증입니다. 병합·배포하지 않습니다.


## Phase21C · 협곡 증분

`scenes/phase21.tscn`에서 Amber Canyon을 선택합니다. 표시된 양 끝에서 기존 상호작용 키로
1.35초 노출 통과로를 사용합니다(큰 소리·8초 재사용). 길이 막히거나 맞으면 이동을 중단하며
원래 우회로는 항상 남습니다. 두 돌풍 구역의 작은 소품8개는 예고 후 짧게 움직이고 원위치로
돌아옵니다. 새 충돌체·무적·피해 규칙은 없습니다. 물/갈대 만료와 듣기 완료가 겹치는 오류도
경계 검사로 재현 후 수정했습니다. 상세 내용은 docs/PHASE21C.md를 참고하세요.
전체 seed 변주는 미포함이며 아직 전체 Phase21 완료가 아닙니다.
