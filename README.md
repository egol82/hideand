# Hide & Smashing — Phase 17

직접 그린 무기로 숨고, 찾고, 반격하는 1인칭 장난감 게임입니다.

## 이번 단계: 대저택 가구와 실내 마감

소파/침대 쿠션·봉제 테두리·목재 받침, 수납장 앞면과 손잡이, 창가 커튼·몰딩·액자, 실내등 갓, 책·컵·수건·장난감 디테일을 추가했습니다. 기존 은신처12곳의 움직이는 가구도 같은 자리/출구를 유지한 채 다듬었습니다.

새 기준은 `phase17/crafted-manor` / `scenes/phase17.tscn`입니다.
**Godot Standard에서 project.godot 열기 → F5 → 숨바꼭질 대저택.**
메뉴/일시정지 → 그래픽 비교 → **가구·실내 마감**으로 이전 모습과 비교합니다.

기존 GI는 그대로 사용하며 고정 가구 위의 새 마감은 프로브로 빛을 받습니다. 가구 전체를 새로 베이크한 것이 아닙니다. 구조·동선·충돌·은신처·무기·타격싱크·애니메이션·저장/키설정은 유지합니다. 나머지6개맵은 이번 리모델링 대상이 아닙니다.

`docs/PHASE17.md`, `docs/PHASE17_TEST_STATUS.md`, `docs/ASTRA_START.md`에 범위와 검증을 기록합니다. 편집용 native 모델을 내보내는 도구도 포함합니다. 실제 사람의 최종 아트/은신 평가와 하드웨어 성능을 인증한 버전은 아닙니다. LICENSE와 이전 브랜치를 보존하고 main에는 자동 병합하지 않습니다.

## 최종 전달 확인 — 2026-09-30

[PR #17](https://github.com/egol82/hideand/pull/17)에서 변경사항을 확인할 수 있습니다.
검증된 게임·모델 생성기·테스트 소스는 `3473fb808ded0c5ab5a6c78a7d180537aa801c00`입니다. 이후 커밋은 검증 문서와 이 전달 안내를 갱신하며 런타임을 변경하지 않습니다.

[Windows/Linux 환경 검사와 실제 렌더](https://github.com/egol82/hideand/actions/runs/36654648372)는 모두 성공했습니다. 최종 전달 과정에서도 원격 소스를 다시 내려받고 공식 Godot4.4.1에서 새 환경 검사116개·기존 접촉 검사94개·기본 씬 초기화·편집용16개 장면 저장/재로딩·7개맵×2개모드14경기를 재실행해 종료코드0과 완료마커를 확인했습니다. 각 경기는4라운드이며 원격Windows/Linux와 결과JSON이 같습니다. 소스286개 파일은 재검증 후에도 원격 ZIP과 바이트 차이가 없습니다. 별도 정적 검사716개도 통과했습니다.

15장의 실제 실행 화면은 성공한 원격 검사에서 생성한 자료를 다시 검수했습니다. 이번 복구에서 새로운 렌더나 추가 모델 재제작을 했다고 주장하지 않습니다. 기존 셰이더 UID가 유효한 텍스트 경로로 대체되는 경고는 남아 있으며, 검사 수는 사람 플레이 횟수나 품질 점수가 아닙니다.

편집용 가구를 내보내려면 `tools/export_environment17.gd`를 사용하세요. 일반 F5에는 별도 내보내기가 필요하지 않습니다. 고정 소파·침대·카운터의 내보내기 결과는 기존 구조물 위에 얹는 마감 모델이며, 독립적인 충돌체/베이크 대체물이 아닙니다. 편집한 복사본이 런타임 생성기에 자동 역반영되지는 않습니다.
