# Hide & Smashing — Phase 8

직접 그린 모양이 무기가 되는 귀여운 1인칭 숨바꼭질·반격 게임입니다.

## 이번 업데이트: 자연스러운 손 그립

- 기존에 떠 있던 두 주먹을 손잡이를 감싸는 네 손가락·엄지·손바닥으로 교체했습니다.
- 실제로 긴 손잡이는 두 손으로 잡고, 짧으면 보조손이 손목을 받칩니다. 없는 손잡이를 그림에 추가하지 않습니다.
- 공격 중에도 손 접촉이 유지되며 손목·천 소매가 이어집니다. 조작 안내는 손과 겹치지 않게 위로 이동했습니다.
- 원본 그림·사거리·타격 표본·점수·시간·이동·맵·저장 규칙은 유지합니다.

## 실행

이 브랜치의 `project.godot` → Godot Standard에서 F5 → 맵 선택 → 연습장 또는 게임 시작.
기본 씬 `scenes/phase8.tscn`, 최신 브랜치 `phase8/viewmodel-polish`. main과 이전 PR은 자동 병합하지 않았습니다.

기존 6개 맵(집·창고·정원·슈가 마켓·별빛 오락실·포켓 기차역), FIELD/CLASSIC, 사람1명+봇3명, 연습장, 탈락 후 제작, 키 변경, 8슬롯 저장·복구와 주요 한/영 UI는 포함됩니다.

기본 조작: WASD 이동, 마우스 시선, LMB 공격, Shift 대시, Ctrl 조용히 이동, E 숨기/검사, C 도발, M 지도, Tab 그림판, Esc 설정.
