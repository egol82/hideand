# Hide & Smashing — Phase 11 Hideaway Manor

직접 그린 입체 장난감 무기로 숨고, 속이고, 들키면 반격하는 1인칭 게임입니다.

**최신 브랜치:** `phase11/hide-and-seek` · **기본 씬:** `scenes/phase11.tscn`.

## 새로 플레이할 것

- 2층 숨바꼭질 대저택: 두 계단, 고리형 동선, 12개 후보 은신처와 두 출구. 매 라운드2곳은 물건이 가득해 숨을 수 없습니다.
- 은신 중 엿보기, 오래 엿보면 눈이 노출되는 위험, 출구 선택, 일반 공격으로 이어지는 기습.
- 가짜 소리 태엽 장난감, 잠깐 남는 발자국/은신처 이탈 흔적, 조용한 카펫과 시끄러운 타일.
- 술래의 귀 기울이기/흔적 조사/소란스러운 빠른 검사, 종반의 넓은 구역 단서.
- 대저택의 빨래 슈트와 라운드당 한 번인 하이더 전용 통로. 둘은 정해진 출구로 이어지는 짧은 연출형 이동입니다.

기존 여섯 맵, 둥근 손과 큰 표시용 무기, 실제 접촉 싱크, Phase10의 A/B/C 그래픽, 연습장, 차기 무기 제작,11개 키 변경,8슬롯 저장·복구는 유지합니다. 기존 여섯 맵에는 새 공통 은신/수색 도구를 적용하고 원래 지형은 보존했습니다. 현재는 사람1명+봇3명 오프라인입니다.

## 실행

Godot Standard에서 `project.godot` → F5 → 맵 → 술래 또는 숨는 역할 시작.
기본 WASD 이동 / 마우스 시선 / LMB 공격 / Shift 대시 / Ctrl 조용한 이동 / E 상호작용 / C 도발 / M 지도 / Tab 그림판 / Esc 일시정지.
**숨은 동안:** E 출구1, Shift 출구2, Ctrl 엿보기, LMB 근처 술래에 기습 도전.
추가 도구는 보통 Q, 술래 도구 변경 R입니다. 기존 저장키와 충돌하면 다른 빈 키를 선택해 HUD에 표시합니다.
