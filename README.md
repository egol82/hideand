# Hide & Smashing — Phase 7

귀여운 1인칭 숨바꼭질·반격 게임. 직접 그린 선과 윤곽이 입체 장난감 무기가 됩니다.

## 새 맵 3개, 전체 맵 6개

- 슈가 마켓: 30×26, 은신처10곳. 케이크·진열대 고리 동선, 시끄러운 타일과 조용한 러그.
- 별빛 오락실: 40×32, 은신처14곳. 게임기·행성 랜드마크, 소리 타일 교차로와 카펫 우회로.
- 포켓 기차역: 52×40, 은신처18곳. 멈춰 있는 객차 사이 갈림길, 시계·가판대·수하물 은신처.
- 기존 장난감 집·창고·비밀 정원도 보존했습니다.

새 맵의 줄무늬 타일은 발소리 단서 범위가 커지고, 민트/파란 러그는 줄어듭니다. 실제 발걸음에서만 단서가 발생합니다. 음악/화면 설정이 게임 규칙을 바꾸지 않습니다.

## 실행

Godot Standard에서 `project.godot` → F5 → 맵 선택 → 게임 시작. 기본 씬 `scenes/phase7.tscn`. 1명+봇3명, FIELD 현장8초/CLASSIC 중앙5초, 4라운드. 연습장·탈락 후 다음 무기 제작·11개 조작 변경·8슬롯 저장 복구·주요 한/영 UI는 유지됩니다.

기본 조작: WASD 이동, 마우스 시선, 왼쪽 클릭 공격, Shift 대시, Ctrl 조용히 이동, E 숨기/검사, C 도발, M 지도, Tab 그림판, Esc 메뉴. 조작키는 설정에서 바꿀 수 있습니다.
