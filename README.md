# Hide & Smashing — Phase 9

직접 그린 장난감 무기로 숨고, 찾고, 반격하는 귀여운 1인칭 파티게임 프로토타입입니다.

## 이번 변경: 스매시 효과와 맞는 인형의 반응

실제 명중에서 짧은 별·폼 조각·링과 한/영 코믹 글씨가 나옵니다. 맞은 인형은 찌그러졌다 돌아오며 팔을 허우적거리고 빙글빙글 눈과 별로 반응합니다. 마지막 타격 뒤 실제로 사라진 인형에는 0.54초의 제자리 퇴장 연출을 남깁니다. 벽에 막힘은 별도 소리·표시를 쓰며 헛스윙은 명중으로 꾸미지 않습니다.

사거리, 손 그립, 체력·점수·시간·이동·저장·6개 맵은 그대로입니다. 효과는 기존 동작 줄이기/접촉 강도 설정을 따르며 플레이어 시선을 강제로 흔들지 않습니다.

## 실행

`project.godot` → Godot Standard F5 → 연습장 또는 게임 시작. 새 씬 `scenes/phase9.tscn`. 최신 브랜치 `phase9/smash-reactions`. main과 앞선 PR은 자동 병합하지 않았습니다.

`docs/PHASE9.md`, `docs/PHASE9_REFERENCE.md`, `docs/PHASE9_TEST_STATUS.md`에 구현·참고·검증을 구분했습니다. `python tools/test_smash.py`로 새 엔진 검사를 실행하며 기존 검사도 유지합니다.

절차적 카툰 연출이며 완전한 물리 래그돌, 사람 재미·멀미 평가, Windows GPU/FPS, 실제 오디오 기기, 온라인/Steam/EXE는 아직 검증 범위 밖입니다. 폰트 파일·유료 에셋·런타임 AI API는 포함하지 않습니다. LICENSE 보존.
