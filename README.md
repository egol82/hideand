# Hide & Smashing — Phase 18

직접 그린 무기로 숨고, 찾고, 반격하는 1인칭 장난감 게임입니다.

## 이번 단계: 타격 효과·사운드·시점 폴리시

새 기준은 `phase18/smash-polish`, 기본 씬은 `scenes/phase18.tscn`입니다.
**Godot Standard에서 project.godot 열기 → F5 → 게임 또는 무기 공방.**

타격은 작은 폼 조각·별·충격 링·짧은 퍼프, 막힘은 적은 조각과 다른 소리로 구별합니다. 명중 문구를 줄이고, 실제 무기의 공격 구간에만 짧은 궤적을 표시합니다. 휘두름과 타격 소리를 유형별로 직접 합성했습니다. 소리·효과·피격은 기존 확정 접촉과 공격 시간을 사용합니다.

카메라를 강제로 흔들지 않고, 접촉 정렬 이후 손의 복귀만 조금 보강합니다. 둥근 손·그린 크기에 비례하는 무기·낮은 대기 자세·타격 싱크, Phase13~17 캐릭터·재질·GI·애니메이션·가구와 일곱 맵을 유지합니다.

메뉴/일시정지 → **그래픽 비교 → 타격 연출 / Smash polish**에서 이전 표현과 비교할 수 있습니다. 동작 줄이기와 효과 강도0은 새 움직이는 효과를 없애며 피해/규칙은 그대로입니다. 음량0과 일시정지가 별도 타격 소리에도 적용됩니다.

`docs/PHASE18.md`, `docs/PHASE18_TEST_STATUS.md`, `docs/ASTRA_START.md`에 범위와 검증을 기록합니다. 새 효과는 실제 물리입자로 지형과 충돌하는 기능이 아니며, 모든 무기의 관통/가림을 해결한 최종판은 아닙니다. 영상의 소리 미리보기는 실제 PCM·이벤트 시점으로 별도 구성한 모노 믹스이고 실제 기기 녹음이 아닙니다.

main과 이전PR은 자동 병합하지 않습니다. LICENSE·공개설정·원본 자산을 유지합니다. 유료 에셋/API, 폰트·엔진 바이너리, 개인 저장 파일은 포함하지 않습니다.
