# Hide & Smashing — Phase 17

직접 그린 무기로 숨고, 찾고, 반격하는 1인칭 장난감 게임입니다.

## 이번 단계: 대저택 가구와 실내 마감

소파/침대 쿠션·봉제 테두리·목재 받침, 수납장 앞면과 손잡이, 창가 커튼·몰딩·액자, 실내등 갓, 책·컵·수건·장난감 디테일을 추가했습니다. 기존 은신처12곳의 움직이는 가구도 같은 자리/출구를 유지한 채 정교하게 다듬었습니다.

새 기준은 `phase17/crafted-manor` / `scenes/phase17.tscn`입니다.
**Godot Standard에서 project.godot 열기 → F5 → 숨바꼭질 대저택.**
메뉴/일시정지 → 그래픽 비교 → **가구·실내 마감**으로 이전 모습과 비교합니다.

기존 GI는 그대로 사용하며 고정 가구 위의 새 마감은 프로브로 빛을 받습니다. 가구 전체를 새로 베이크한 것이 아닙니다. 구조·동선·충돌·은신처·무기·타격싱크·애니메이션·저장/키설정은 유지합니다. 나머지6개맵은 이번 리모델링 대상이 아닙니다.
