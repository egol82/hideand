# Hide & Smashing — Phase19

직접 그린 무기로 숨고, 찾고, 반격하는 장난감 게임입니다.

Phase19는 기존 일곱 맵의 공통 캐릭터·재질·애니메이션·타격을 유지하고, 대저택 외 여섯 맵의 마감과 직접 조명을 다듬습니다. 새 반복 장식은8m 공간별 MultiMesh로 묶고 작은 장식에만 거리 옵션을 적용합니다. 엄폐·은신처·판정은 사라지지 않습니다. 대저택 GI는 보존하며 나머지 맵을 새로 베이크한 버전은 아닙니다.
