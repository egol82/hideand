# Hide & Smashing — Phase 15

Godot 기반 1인칭 그림 무기 숨바꼭질. 이번 단계는 실제 대저택 조명과 LightmapGI 연결입니다.

`project.godot` → F5 → 숨바꼭질 대저택. 메뉴/일시정지의 그래픽 비교에서
조명 A(이전), B(새 직접광), C(직접광+실제 GI)를 비교합니다. 기존 재질1/2세대는 유지합니다.

고정 벽·바닥·계단·가구는 베이크, 라운드 가구·캐릭터·무기는 프로브를 사용합니다.
발밑 접촉 보강은 별도 선택이며 실제 물리 그림자에 더하는 절제된 보조 표현입니다.
GI 자료가 없거나 고정 구조가 달라지면 이를 알리고 직접광으로 돌아갑니다.
