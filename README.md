# Hide & Smashing — Phase 16

직접 그린 무기로 숨고, 찾고, 반격하는 1인칭 장난감 게임입니다.

## Phase16 — 캐릭터 애니메이션 + 손/발 IK

기본 씬 `scenes/phase16.tscn`, 브랜치 `phase16/animation-ik`.
`project.godot` → Godot Standard에서 F5 → 게임 또는 무기 공방.

대기·걷기·달리기·숨기·엿보기·무기 준비·공격 준비·타격·피격·회복·KO·공중의12개 실제 스켈레탈 클립을 사용합니다. 공격 시간과 접촉은 기존 게임이 결정하며 새 모션은 그 시간을 읽습니다. 손은 원본 무기의 실제 축을 따라가고, 발은 바닥 레이와 서 있는 발의 월드 위치를 이용해 보정합니다.

일곱 맵, Phase15의 실제 대저택 GI, Phase14 재질, 연결된18뼈 캐릭터, 둥근1인칭 손, 비례 무기크기와 낮은 자세, 메뉴와 숨바꼭질 기능은 유지합니다. 이전 씬은 이전 포즈 방식으로 실행됩니다.

`docs/PHASE16.md`, `docs/PHASE16_TEST_STATUS.md`에서 구현과 검증 한계를 확인하세요. 모든 그림에 완벽한 양손 접촉·무관통·발미끄러짐 제거를 보장하는 전신IK나 모션캡처 라이브러리는 아닙니다. 게임패드·온라인·Steam·EXE나 사람 QA는 별도입니다.

원래 조작 그대로입니다. 추가 유료 에셋·API·폰트·엔진 파일은 포함하지 않습니다. main과 이전PR은 자동 병합하지 않습니다.
