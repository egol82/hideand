# Hide & Smashing · Phase 3

**직접 그린 무기를 손에 들고 탐색하는 1인칭 숨바꼭질 난투 프로토타입.**

Godot Standard + GDScript. 사람 1명 + 봇 3명, 오프라인 4라운드. 기존 Phase 1/2 게임 씬과 사용자 LICENSE는 보존합니다. 온라인/Steam/유료 에셋/런타임 AI API는 없습니다.

## 시작

`project.godot`를 Godot Standard에서 열고 F5를 누릅니다. 기본 씬은 `scenes/phase3.tscn`입니다.
메뉴에서 맵을 선택하고 **PLAY — SEEK FIRST** 또는 **PLAY — HIDE FIRST**를 누릅니다.
그림판에서 직접 그린 뒤 준비하면 원래 윤곽을 유지한 입체 무기가 손에 장착됩니다.

| 맵 | 크기 (월드 단위=미터로 표기) | 은신처 | 숨기 / 탐색 |
|---|---:|---:|---:|
| Toy House | 24 × 20 | 8 | 14 / 80초 |
| Toy Warehouse | 48 × 36 | 14 | 22 / 135초 |
| Secret Garden | 80 × 56 | 24 | 32 / 210초 |

단순 확대가 아닌 별도 방/선반/울타리 동선입니다. 사람과 무기의 크기·사거리는 맵에 따라 커지지 않습니다.

## 조작

| 입력 | 기능 |
|---|---|
| 마우스 | 좌우·상하 시선 |
| WASD | 바라보는 방향 기준 이동 |
| 왼쪽 클릭 | 결투 중 무기 휘두르기 |
| Shift | 대시 / 회피 |
| E | 가까운 은신처를 바라보고 숨기 또는 검사, 숨어 있을 때 나오기 |
| C | 도발 단서 |
| M | 자기 위치와 공개 은신처만 보이는 지도; 게임 일시정지 |
| Esc | 일시정지·설정·커서 해제 |
| F11 / F12 | 전체 화면 / 실제 실행 화면 저장 |

마우스 감도, 세로 시야각, Y축 반전, 효과음 볼륨, 동작 줄이기는 일시정지 설정에 있습니다.

## 1인칭 구현

자기 눈높이의 원근 카메라, 화면 아래 두 손과 실제 그림에서 생성한 무기, 조준점·방위·E 상호작용 안내를 제공합니다. 자기 머리/몸/이름표는 해당 카메라에만 보이지 않습니다. 무기는 주변과 같은 무광 장난감 재질과 광원을 사용합니다.

손에 보이는 무기는 카메라용 표시본이며 실제 타격은 원래 월드 무기의 선/채움 샘플로 계산합니다. 표시 크기 조절은 공격력·사거리를 바꾸지 않습니다. 벽 가까이에서는 무기를 당기거나 감춥니다.

발견은 시야 앞쪽과 장애물 차단 검사를 따릅니다. 다른 두 명이 결투하는 동안 또는 자신이 잡힌 뒤에는 명시적인 1인칭 관전 화면으로 전환합니다.

## 규칙

무기 그리기 → 숨기 → 탐색 → 발견/무기 공개 → 5초 결투 → 포획·탈출 → 결과. 발견된 두 명은 중앙 결투 구역으로 이동하고 나머지 진행은 정지합니다. 탈출하면 발견됐던 장소 근처로 돌아옵니다. 배틀로얄·총기 게임으로 변경한 것이 아닙니다.

## 개발·검증

```bash
python3 tools/verify_project.py
GODOT_BIN=/path/to/godot bash tools/test.sh
GODOT_BIN=/path/to/godot bash tools/test_phase3.sh
```

Windows: `tools/test.ps1` 실행 후 `tools/test_phase3.ps1`을 `-Godot` 실행기 경로로 실행합니다.
검증 범위와 정확한 결과는 `docs/TEST_STATUS.md`, 인계는 `docs/ASTRA_START.md`, 변경 명세는 `docs/PHASE3.md`를 확인합니다.

기존 게임: `scenes/main.tscn` (Phase 1), `scenes/phase2.tscn` (Phase 2).
현재는 절차적 아트의 엔진 프로토타입이며, 콘셉트 원화 수준의 완성도·사람 플레이테스트·Windows GPU/FPS·배포 EXE·Steam 출시를 검증했다는 뜻은 아닙니다.
