# Hide & Smashing — Phase 15

직접 그린 무기로 숨고, 찾고, 반격하는 1인칭 장난감 게임입니다.

## 이번 단계: 대저택의 실제 조명과 GI

기본 실행은 `scenes/phase15.tscn`, 작업 브랜치는 `phase15/manor-lighting-gi`입니다.
Godot Standard에서 `project.godot`을 열고 F5를 누르면 됩니다. 기존 7개 맵·모델·재질·숨바꼭질·저장 기능은 포함됩니다.

숨바꼭질 대저택은 실제 저장된 LightmapGI를 실전 장면에 연결합니다. 326개 고정 메시의 UV2와 베이크 텍스처, 동적 프로브가 저장소에 포함되어 있어 게임 실행 시 다시 굽지 않습니다.

메뉴/일시정지 → 그래픽 비교에서 **조명 A 이전 / B 새 직접광 / C 동일 직접광+GI**를 비교합니다. 기본값 C입니다. 재질 1·2세대와 접촉 보강은 따로 선택합니다. 조명 비교는 대저택 전용이고 나머지 맵은 이전 조명을 유지합니다.

캐릭터·그린 무기·1인칭 무기는 프로브로 간접광을 받습니다. 움직이는 은신 가구를 정적 베이크에 포함하지 않습니다. 발밑의 작은 보조 음영은 바닥에 맞춰 움직이며, 숨은 참가자를 노출하지 않습니다. 이것을 SSAO나 광선 추적 그림자라고 부르지 않습니다.

창문은 기존 불투명 장식을 유지해 내부 창빛 광원으로 표현합니다. 실제 유리 투과나 새로운 창구멍/충돌을 추가하지 않았습니다. 정적 구조의 두 층을 베이크했지만 이번 아트 검수의 대표는 1층 거실입니다.

최초 에디터 베이크의 종료 오류와 복구 경위는 검증 문서에 구분합니다. 새 간접광의 실제 픽셀/프로브 수신 검사를 헤드리스 노드 존재 검사와 혼동하지 않습니다.
