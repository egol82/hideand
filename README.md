# Hide & Smashing — Phase 2

**직접 그린 무기로 탈출하는 귀여운 숨바꼭질 난투 게임의 오프라인 프로토타입.**

Godot Standard + GDScript. 사람 1명과 봇 3명으로 4라운드를 플레이한다. 기존 Phase 1 무기 실험실은 `scenes/main.tscn`에 보존했다. 기본 실행 화면은 `scenes/phase2.tscn`이다.

## 이번 단계에서 플레이하는 것

무기 그리기 → 숨기 → 탐색 → 발견 → 무기 공개 → 5초 결투 → 포획/탈출 → 라운드 점수 → 최종 결과.

- 술래부터 / 숨는 역할부터 시작 가능. 매 라운드 술래가 바뀐다.
- 숨을 장소 6곳, 장애물 우회 경로 탐색, 시야·벽 차단, 숨은 장소 검사.
- 술래는 숨기 시간에 화면을 볼 수 없다. 숨은 플레이어의 모델·이름표·충돌을 함께 감춘다.
- 발견되면 중앙 러그에서 둘이 결투한다. 다른 참가자와 탐색 타이머는 잠시 멈춘다.
- 숨은 쪽이 5초 버티거나 술래를 쓰러뜨리면 탈출하며, 5초간 다시 발견되지 않는다.
- 포획 +3점, 탈출 +2점, 라운드 생존 +2점, 전원 포획 보너스 +2점. 동시 KO는 숨은 쪽의 탈출.
- 무기 8개 로컬 저장 슬롯, 실시간 3D 미리보기, 손잡이 지정, 5색 팔레트, 지우기·되돌리기.
- 일시정지/도움말, 창 전환 시 자동 일시정지, 효과음 볼륨, 화면 흔들림/미리보기 회전 끄기, 전체 화면, 실제 화면 캡처.

## 그림은 실제 무기 형태로 유지한다

기성 무기로 치환하거나 AI API를 호출하지 않는다. 원래 선을 둥근 3D 튜브로 만들고, **단순하게 닫힌 윤곽에는 얕은 입체 면을 채우는 옵션**을 추가했다. 무기와 캐릭터·가구는 같은 무광 장난감 재질/조명을 사용한다. 채운 면의 안쪽에도 타격 샘플을 배치한다.

복잡한 자기 교차, 구멍, 지나치게 긴 윤곽 등은 튜브 표현으로 남긴다. 완성형 입체 물고기/망치를 의미 인식해 복원하는 기능은 아니다.

## 시작

1. GitHub 브랜치 `phase2/offline-match`를 받는다. PR 병합 전에는 `main`에 Phase 2가 없다.
2. Godot Standard에서 `project.godot`를 열고 F5.
3. `PLAY — SEEK FIRST` 또는 `PLAY — HIDE FIRST`를 선택한다.
4. 무기를 그리거나 예시를 수정한 뒤 `READY`를 누른다.

Godot 4.4.1 및 4.7.2를 CI 대상으로 사용한다. 실행기 자체는 저장소에 포함하지 않는다. 테스트 상태와 남은 한계는 `docs/TEST_STATUS.md`, `docs/PHASE2.md`를 확인한다.

| 입력 | 동작 |
|---|---|
| WASD / 마우스 | 이동 / 조준 |
| 왼쪽 클릭 / Shift | 결투 중 휘두르기 / 대시 |
| E | 숨기·나오기 / 술래의 장소 검사 |
| C | 도발: 효과음과 위치 단서 노출 |
| Esc | 일시정지와 도움말 |
| F11 / F12 | 전체 화면 / 실제 실행 화면 저장 |

## 검증

```bash
python3 tools/verify_project.py
GODOT_BIN=/path/to/godot bash tools/test.sh
```

```powershell
./tools/test.ps1 -Godot 'C:\Tools\Godot\Godot_console.exe'
```

테스트는 기존 무기 테스트, Phase 2 상태·메시·경로 테스트, 입력 처리 통합 테스트, 두 씬 시작 검사, 봇 4라운드 자동 진행을 수행한다. Linux CI는 소프트웨어 OpenGL에서 실제 화면 5장도 남긴다. 자동 테스트는 사람의 재미·조작성 평가가 아니다.

## 범위
