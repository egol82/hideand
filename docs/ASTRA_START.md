# Astra — Phase17 environment handoff

Use phase17/crafted-manor, scenes/phase17.tscn. Read AGENTS.md, PHASE17.md and PHASE17_TEST_STATUS.md.

The new Environment17 node only owns nested scenery. Original Phase16 animation/IK, Phase15 static326 GI users and their hashes, Phase14 shader, Phase13 character and proportional lowered viewmodel stay intact. Fixed-core refinements are probe-lit detail shells, not freshly rebaked geometry. Any future major silhouette/core change needs an explicit rebake.

Homes keep their exact parent/collider/ports/parcel cues. Recipes never use occupancy/fake flags. Dynamic home replacements still cast direct shadows. Test map/seed lifecycle and independent art/material/light toggles; no per-frame rebuilding. Fine fixed trim intentionally does not cast needle shadows.

Run tools/test_environment17.py --matches and all inherited runners. Render --capture under a display/Xvfb and inspect actual before/after pixels. Native .scn exports are generated by tools/export_environment17.gd for editing, not automatically imported back into gameplay. Do not ship engines/fonts/caches/saves or claim an automatic screenshot is a human test. Keep LICENSE/branches and avoid unrequested merges.
